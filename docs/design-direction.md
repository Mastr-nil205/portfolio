# Bootstrap design directions

Direction A explicitly selected on 2026-10-20. Both use semantic HTML and Bootstrap 5 grids with custom CSS.

## A — Technical editorial (selected)

Navy/charcoal, ivory display type, teal accents, fine borders, generous spacing. Two-column hero: introduction and an index of enterprise IT, development, and independent learning.

Desktop composition: custom navbar → introduction/focus index → featured technical project → professional approach → contact → minimal footer.

Mobile: accessible menu; stacked hero; full-width project entry; stacked supporting sections.

Use `.container`, `.row`, responsive `.col-*`, selected form controls, and customized Bootstrap variables. Typography and border treatments supply a distinct identity. Strong fit for the brief; requires disciplined spacing/contrast.

## B — Field notes (alternative)

Warm white, charcoal, muted blue, serif headlines, ordered project journal. Same Bootstrap grid and templates, alternate tokens.

Desktop: headline/personal note → project reading list → experience → contact. Mobile: single-column sequence.

Approachable editorial character, but less aligned with the requested dark palette.

## Boundaries

Navigation: Home, About, Experience, Projects, Resume, Contact. No private business sections, sales calls to action, invented metrics/projects, or dead resume links. Respect reduced motion.
